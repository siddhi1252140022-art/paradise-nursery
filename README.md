# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Project Description
Paradise Nursery is an online plant shopping application where users can browse plants, view plant details, add plants to a shopping cart, and manage their cart items.

## Features
- Browse houseplants by category
- View plant names, prices, and images
- Add plants to the shopping cart
- Increase or decrease quantities
- Remove plants from the cart
- View the total cart amount
- Continue shopping from the cart
- Checkout functionality
